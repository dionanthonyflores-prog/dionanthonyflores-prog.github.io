How I work

How I test

The same steps whether it's an insurance system or a small business website.

  1. Understand

    Read the requirements and ask what matters most to the business and its users.

  2. Plan

    Decide what to test, what not to, on which devices, and what "done" means.

  3. Design

    Write test cases from boundaries, edge cases and real user journeys, each traced to a requirement.

  4. Test

    Run them by hand where judgment matters, and automate the ones that should run every time.

  5. Report and retest

    Log bugs with steps and evidence, then confirm the fix and keep a regression test.
